# 📊 EDA Analyzer — Complete Project

An interactive web app that performs Exploratory Data Analysis (EDA) on any CSV/Excel dataset and generates AI-powered insights using Groq's LLaMA 3.3 70B Versatile model, built with Streamlit.

---

## 🚀 Features
- Upload CSV or Excel files
- Automatic dataset overview (rows, columns, duplicates, missing values)
- Data type summary
- Missing value analysis (count + percentage)
- Statistical summary (mean, median, std, etc.)
- Interactive visualizations: histogram, correlation heatmap, bar chart
- AI-generated insights via Groq API
- Ask follow-up questions about your dataset (chat feature)

## 🛠️ Tech Stack
| Component | Technology |
|---|---|
| Frontend / UI | Streamlit |
| Data Handling | Pandas, NumPy |
| Visualization | Matplotlib, Seaborn, Plotly |
| AI / LLM | Groq API (llama-3.3-70b-versatile) |
| Environment Variables | python-dotenv |
